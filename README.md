### Main Projects

<table>
  <tr>
    <td width="30%" valign="top"><b><a href="https://github.com/varshakodi/docket">Docket</a></b><br><sub>Go · PostgreSQL · gRPC · Docker</sub></td>
    <td valign="top">A durable, horizontally scalable job queue on PostgreSQL. Workers claim with <code>FOR UPDATE SKIP LOCKED</code>; leases recover jobs from crashed workers; failures retry with jittered backoff and land in a dead-letter queue. Includes a gRPC API, an HTTP job type with SSRF protection, Prometheus metrics, a dashboard, and fault-injection tests that kill real worker processes.</td>
  </tr>
  <tr>
    <td width="30%" valign="top"><b><a href="https://github.com/varshakodi/TravelRiskAggregator">TravelRiskAggregator</a></b><br><sub>FastAPI · PostGIS · React · Leaflet</sub></td>
    <td valign="top">A flight-routing engine that plans around live hazards — SIGMET weather polygons and USGS earthquakes — using Dijkstra over PostGIS great-circle geometry, and reports when no safe path exists.</td>
  </tr>
  <tr>
    <td width="30%" valign="top"><b><a href="https://github.com/varshakodi/SchemeSetu">SchemeSetu</a></b><br><sub>Python · LangGraph · BM25 · Cross-Encoder</sub></td>
    <td valign="top">A bilingual (English/Hindi) retrieval-augmented question-answering system over Indian welfare schemes. Answers cite their sources and the system refuses when the corpus cannot support an answer; 0.96 hit@5 and 100% out-of-corpus refusal on a frozen benchmark.</td>
